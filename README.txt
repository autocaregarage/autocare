AUTOCARE DEMO WEBSITE

Files:
- index.html: page content
- style.css: layout and visual design
- script.js: mobile navigation and footer year

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open the autocare-website folder.
3. Double-click index.html to open it in a browser.
   Internet is needed for the external photos and Google Fonts.

IMPORTANT BEFORE SELLING/PUBLISHING FOR A CLIENT
- This is a demo/template, not a real auto repair business.
- Replace the sample phone, email, address, business name, services, and all other details.
- The customer quotes are placeholders, not real testimonials. Replace with genuine approved reviews or remove the section.
- Check that all photos are suitable for the intended commercial use and replace them if needed.
- Appointment button currently opens an email draft; it is not a booking system.
- GitHub Pages is suitable for static HTML/CSS/JS sites. A custom domain, form backend, booking system, or other features may cost extra.
